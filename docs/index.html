Smart Parking Allocation System

A browser-based parking dashboard backed by Java 17 and Spring Boot. Dijkstra shortest-path allocation, permit checks, overlap detection, waiting-list priority and fee calculation all run in the backend.

Java 17 Spring Boot 3.3.5 Spring Data JPA MySQL Maven HTML / CSS / JS
Static showcase only. This GitHub Pages site cannot run the Java backend or MySQL database. Run the project locally or deploy it to a Java host to use the live dashboard.

What it does

  • 3 connected lots with 24 car, two-wheeler and accessible spaces
  • Nearest-space allocation using Dijkstra travel times
  • Reservation lifecycle: reserved, checked in, completed, cancelled, expired
  • Priority waiting list rebuilt from MySQL on startup
  • Audit history with parking fee calculation
  • Simulated clock for expiry and fee demonstrations

Features

Built around real parking rules

Allocation

Smart nearest space

Ranks compatible spaces by Dijkstra travel time, then floor, then space code.

Validation

Overlap protection

Half-open interval checks, row locks and optimistic versioning prevent double booking.

Waiting list

Priority queue

Permit holders rank first, then arrival time, with automatic reallocation after releases.

Billing

Fee calculation

Car Rs.50/hour, two-wheeler Rs.20/hour, minimum one hour and part hours rounded up.
